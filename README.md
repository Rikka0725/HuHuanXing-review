## 为什么做这个

复习《互换性与测量技术》时，知识点往往分散在复习提纲、PPT 和笔记里：

- 想查一个概念，要翻好几份文件；
- 想背一道简答题，题目、评分点和易错点不在同一页；
- 打印时，折叠的内容容易被漏掉。

于是把这些内容整理成一个单文件网页：左边目录、顶部搜索、按章折叠，手机和打印都能用。

适合正在复习这门课的同学，也适合想快速查几何公差、表面粗糙度、螺纹、齿轮、尺寸链等概念的人。

## 功能

| 功能 | 说明 |
|---|---|
| 单文件网页 | `期末复习.html` 内嵌 CSS/JS，无构建步骤、无外部 CDN，离线可用 |
| 快速检索 | 顶部搜索框可过滤知识点、题目、评分点和对比表 |
| 按章折叠 | 左侧章节目录，支持展开/折叠全部 |
| 简答题卡片 | 复习PDF原文 → 答案要点 → 可能简答题 → 评分点 → 易错点 → 资料依据 |
| 考前冲刺 | 必背清单、模拟题评分点、易混概念对比表集中在一页 |
| 手机阅读 | 响应式布局，窄屏表格横向滚动 |
| 打印友好 | 打印时自动展开所有折叠内容，隐藏目录、搜索框和按钮，可直接打印或导出 PDF |

## 快速开始

### 直接打开

双击 `期末复习.html`，用浏览器打开即可。

### 本地服务器

在项目目录运行：

```bash
python -m http.server 8000
```

然后打开：

```text
http://localhost:8000/期末复习.html
```

### 使用建议

- 复习知识点时，用顶部搜索框输入关键词，例如“公差”“量块”“泰勒原则”。
- 考前背诵时，先看各章“本章必背清单”，再用“本章自测题”检查。
- 需要纸质版时，使用页面右上角“打印”按钮，打印前会自动展开全部折叠内容。
- 手机阅读时，点击左上角“☰”打开章节目录；表格可左右滑动。

## 技术说明

- 单文件 HTML，内嵌 CSS/JS，无构建步骤、无外部依赖。
- 公式按原文以纯文本展示，未使用 KaTeX/MathJax，因此不需要联网 CDN。
- 搜索通过前端 JavaScript 过滤卡片和表格；折叠使用原生 `<details>`。
- 打印样式通过 `@media print` 实现，打印前自动展开所有折叠内容。
- 建议使用较新的 Chrome、Edge、Firefox 或 Safari 浏览器。

## 部署到 GitHub Pages

如果想把它发布成在线页面：

1. Fork 或克隆本仓库。
2. 将 `期末复习.html` 复制或重命名为 `index.html`。
3. 提交并推送到 `main` 分支。
4. 打开仓库 **Settings → Pages**。
5. **Build and deployment → Source** 选择 **Deploy from a branch**。
6. **Branch** 选择 `main`，**Folder** 选择 `/ (root)`，保存。
7. 等待 1–2 分钟，访问仓库的 Pages 地址。

也可以把网页放到 `docs/index.html`，在 Pages 中选择 `main` 分支的 `/docs` 目录。
